| 文件 | 内容 | 更新时机 |

## 规则（园艺）

- **新增文档必须在上面「文件职责」表登记**——`tests/docs.test.ts` 会校验「索引 = 实际文件」。
- **相对链接必须可点**（CI/`npm test` 校验）；引用仓库外路径时写明「不在本仓库」。
- **过期内容是债**：删掉，或标「已废止（YYYY-MM-DD）+ 原因」，不要留幽灵文档。
- **数字只在一处写死**（README 的测试文件数 / 验收标准的基线）；其余位置写「以 `npm test` 输出为准」。
- **季度园艺**：复核日期、清理过期条目、把 `AGENTS.md` 里变长的细节搬到这里。
