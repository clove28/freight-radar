## 你在服务器上做的（SSH，按顺序）

> 登录：`ssh root@你的公网IP`

### 2. 一键部署（装 Docker + 构建 + 启动）

```bash
cd /opt/freight-radar
bash deploy/alicloud-setup.sh
```

### 3. 填 key（火山 DeepSeek + 高德）

```bash
cd /opt/freight-radar
nano .env   # 填 ARK_API_KEY / ARK_MODEL / AMAP_KEY / AUTH_REQUIRED=1
docker compose up -d --build   # 重新构建生效
```

### 4. 域名解析（阿里云控制台）

- 域名 → 解析 → 添加 `A` 记录：
  - 主机记录 `@` 和 `www`，值 = **服务器公网 IP**

### 5. 配 HTTPS（域名 + 免费证书）

```bash
cd /opt/freight-radar
bash deploy/https-setup.sh 你的域名
```

### 6. 验证

```bash
curl https://你的域名/api/health   # 返回 {"ok":true}
curl http://localhost:3000/api/health
# 手机 4G 访问 https://你的域名
```

## ⚠️ 备案（国内必须，否则域名无法访问）

- 阿里云控制台 → **ICP 备案** → 提交（身份证/手机号/人脸）
- 审核 1-3 周，期间用 `http://公网IP:3000` 测试（不能公开）
- 备案通过后域名正式可用
