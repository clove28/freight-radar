# 货运雷达 · 局域网使用方案（零成本，给老爸先用）

> 不需要服务器、域名、备案。让手机连**同一个 WiFi**，访问电脑的局域网 IP 即可用。
> 这是"给老爸用"最省事的第一步，零成本、零合规风险。

## 一、电脑端：启动服务

双击运行 `start.ps1`（或命令行）：
```powershell
cd D:\字研班\货车\货运雷达
.\start.ps1
```

服务启动后，在电脑上打开 `http://localhost:3000` 确认正常。

## 二、找电脑的局域网 IP

在**同目录**运行 `deploy\局域网查看IP.ps1`，或命令行：
```powershell
ipconfig | findstr IPv4
```
会看到类似 `192.168.1.5` 的地址。记下它。

## 三、手机/老爸手机：访问

1. 手机连**和电脑同一个 WiFi**
2. 浏览器打开 `http://192.168.1.5:3000`（换成你查到的 IP）
3. 首次可能需要 Windows 防火墙放行：弹窗选"允许访问"；或手动在防火墙放行 3000 端口

## 四、手机添加到主屏幕（像 App 一样用）

- 手机浏览器打开后 → 菜单 → **"添加到主屏幕"**（Safari/Chrome 都有）
- 就会像 App 一样全屏出现，图标 🚛

## 五、遇到问题

| 现象 | 解决 |
|---|---|
| 手机打不开 | 确认同一 WiFi；确认电脑防火墙放行 3000；确认服务在跑 |
| 打开是乱码/加载不出 | 换 Chrome/Edge 浏览器；确认是 http 不是 https |
| 想固定 IP | 路由器里给电脑设 DHCP 静态 IP，或电脑设固定 IP |

## 备注

- **局域网方案**：数据存电脑本地（SQLite），手机访问的是同一份数据
- **只给家里/亲戚用**：完全够，且不涉及公网合规
- 想**真正推广到外地/公网**：走 `部署上线指南.md` 路径 B（服务器+域名+备案）
