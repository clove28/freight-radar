# 货运雷达 · 上线检查清单（P9）

> 从"本地演示"到"真正给司机用"的核对表。按顺序逐项打勾。

## 一、基础设施

- [ ] **HTTPS**：域名 + 证书（Let's Encrypt 免费），参考 `deploy/nginx.conf.example`
- [ ] **WebSocket 反代**：Nginx 需配 Upgrade 头（示例已含），否则 /api/ws 不工作
- [ ] **持久化**：`PERSIST=sqlite` + 数据卷挂载（Docker 已含 `VOLUME /app/data`）
- [ ] **备份策略**：`data/freight-radar.db` 定期备份（cron 或云盘同步）
- [ ] **环境变量**：按 `.env.example` 配置生产值（不要用演示默认）
- [ ] **阿里云专属**：安全组放行 3000/80/443；域名 A 记录指向公网 IP；ICP 备案（国内必须）
- [ ] **Docker 版本**：用 `node:24-alpine` 镜像（Dockerfile 已改），`node:sqlite` 稳定
- [ ] **公网 IP 测试**：先用 `http://公网IP:3000` 验证，再切域名 + HTTPS

## 二、安全

- [ ] **开启鉴权**：`AUTH_REQUIRED=1`（当前默认关闭，仅本地演示）
- [ ] **短信服务商**：接入阿里云/腾讯云 SMS，替换演示 devCode 返回
- [ ] **密码强度**：建议注册时校验 ≥8 位（当前 ≥4 位，本地演示标准）
- [ ] **HTTPS 强制**：HTTP → HTTPS 301（示例已含）
- [ ] **限流**：短信 60s/次、每小时 5 次（已实现）；可加登录失败次数锁定

## 三、数据

- [ ] **真实货源 API**：实现 `ApiCargoRepository`（接口已就绪），替换 Mock 数据
- [ ] **真实行情**：实现 `QuoteProvider`（接口已就绪），替换规则区间
- [ ] **高德 Key**：`AMAP_KEY` 配置后路线/天气/POI 真实化
- [ ] **数据校验**：上线前清空演示数据（订单/信用/司机），干净起步

## 四、多端

- [ ] **小程序真机联调**：正式 AppID + HTTPS 域名白名单（开发者工具"不校验域名"仅限开发）
- [ ] **小程序云同步**：真机测试上传/下载订单（"我的"页云同步卡）
- [ ] **多司机验证**：两台设备登录不同账号，确认档案隔离

## 五、监控与运维

- [ ] **请求日志**：`LOG_REQUESTS=1` 开启后接日志采集（可加结构化输出）
- [ ] **健康检查**：`/api/health` 接入云监控/探活
- [ ] **会话清理**：已实现启动清理；长运行可加定时清理（如每日）
