# 货运雷达 · 公网部署上线指南（路径 B）

> 目标：让货运雷达跑在公网，手机/外地也能访问。
> ⚠️ 前置：需要**云服务器 + 域名**（个人可申请）。国内服务器必须 ICP 备案。

---

## 一、准备（需要你花钱/实名）

| 资源 | 怎么弄 | 大概成本 |
|---|---|---|
| 云服务器 | 阿里云/腾讯云/华为云 轻量应用服务器（Linux，如 Ubuntu 22.04） | 几十元/月 |
| 域名 | 阿里云/腾讯云 注册（实名） | 几十元/年 |
| ICP 备案 | 服务器商后台提交（需身份证/手机号/人脸） | 免费，需几天~3周 |
| HTTPS 证书 | Let's Encrypt 免费（acme.sh 自动续） | 免费 |

> 建议选**轻量应用服务器**（自带简单配置，最省心）。入门选 2核2G 即可，够 20-50 人用。

---

## 二、服务器上装 Docker

登录服务器（SSH），执行：
```bash
# 装 Docker（Ubuntu 示例）
curl -fsSL https://get.docker.com | bash
sudo systemctl enable --now docker
# 装 Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose
```

## 三、把项目传上去

方式 A：**GitHub 仓库**（推荐，好维护）
```bash
# 本地
cd D:\字研班\货车\货运雷达
git init && git add . && git commit -m "货运雷达 v1"
git remote add origin 你的仓库地址
git push -u origin main
# 服务器
git clone 你的仓库地址 /opt/freight-radar
```

方式 B：**scp 直接传**（无 GitHub 也行）
```bash
scp -r D:\字研班\货车\货运雷达 user@服务器IP:/opt/freight-radar
```

## 四、服务器上配置 .env

```bash
cd /opt/freight-radar
# 用 .env.example 建 .env，填你上线的 key
cp .env.example .env
nano .env   # 填 ARK_API_KEY / AMAP_KEY / PERSIST=sqlite / DATA_DIR=/app/data / AUTH_REQUIRED=1
```

## 五、Docker 一键跑

```bash
docker compose up -d --build
docker compose logs -f   # 看启动日志，确认 AI 引擎: 火山方舟，端口 3000
```

> docker-compose.yml 已配：SQLite 持久化（数据卷）、火山/高德/鉴权环境变量全透传。

## 六、配 HTTPS + 域名（Nginx）

用 `deploy/nginx.conf.example`，Let's Encrypt 签证书：
```bash
# 装 acme.sh 并签证书（替换域名）
curl https://get.acme.sh | sh
~/.acme.sh/acme.sh --issue -d 你的域名 --standalone
# 生成后改 nginx.conf 指向证书路径，见 nginx.conf.example
docker run -d --name nginx -p 80:80 -p 443:443 -v /opt/freight-radar/deploy/nginx.conf:/etc/nginx/conf.d/default.conf -v ~/.acme.sh/你的域名/:/etc/letsencrypt/live/你的域名/ --restart unless-stopped nginx
```

> Nginx 同时反代 API + 前端 SPA + WebSocket（/api/ws）。详见 `nginx.conf.example`。

## 七、备案

国内服务器绑定域名，**必须先 ICP 备案**（服务器商后台提交，审核期间域名不能对外服务）。备案通过后域名才能正常访问。
