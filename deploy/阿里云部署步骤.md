# 🚛 货运雷达 · 阿里云部署完整步骤

> 目标：把货运雷达部署到阿里云轻量应用服务器，公网可访问。
> ⏱️ 首次约 1-2 小时（不含备案）。备案另需 1-3 周。

---

## 第 0 步：你要准备什么

- 阿里云账号（实名）
- 一个域名（阿里云注册，几十元/年，需实名）
- 身份证/手机号（备案用）

---

## 第 1 步：买服务器（轻量应用服务器）

1. 登录阿里云 → **轻量应用服务器**（不是 ECS，轻量更省心）
2. 选购：
   - **地域**：选离你近的（华北/华东）
   - **镜像**：选 **Ubuntu 22.04**（最稳）
   - **套餐**：2核2G 起步（够 20-50 人用），带宽 3-5M
   - 按量或包月都行，推荐包月
3. 购买后，控制台给你：**公网 IP**、**root 密码**（或密钥对）

## 第 2 步：安全组放行端口

在服务器控制台 → **防火墙/安全组** → 放行：
- `3000`（应用端口，测试用）
- `80`、`443`（上线时要，HTTP/HTTPS）
- `22`（SSH，通常已开）

## 第 3 步：连接服务器 + 装 Docker

用 SSH 连上（Windows 用 PowerShell / 或控制台"远程连接"）：
```bash
ssh root@你的公网IP
```
然后把项目传上去（在你本地电脑操作）：
```bash
# 用 scp 把整个项目传到服务器
scp -r D:\字研班\货车\货运雷达 root@你的公网IP:/opt/freight-radar
```

在服务器上（root 下）：
```bash
cd /opt/freight-radar
bash deploy/alicloud-setup.sh   # 一键装 Docker + 构建 + 启动
```

## 第 4 步：填 key

脚本已生成 `/opt/freight-radar/.env`，编辑填你的 key：
```bash
cd /opt/freight-radar
nano .env   # 填 ARK_API_KEY（火山 DeepSeek）、AMAP_KEY（高德）；PERSIST=sqlite；AUTH_REQUIRED=1
# 保存后重启
docker compose up -d --build
```

## 第 5 步：验证

```bash
curl http://localhost:3000/api/health    # 应返回 {"ok":true...}
# 浏览器打开 http://你的公网IP:3000
```
> ⚠️ 此时用公网 IP + 3000 端口访问，**只是测试**。正式用**域名 + HTTPS**（见第 7 步）。

## 第 6 步：域名解析

1. 阿里云域名控制台 → 解析 → 添加记录：
   - 记录类型 `A`
   - 主机记录 `www` 和 `@`
   - 值填：**服务器公网 IP**

## 第 7 步：HTTPS（Let's Encrypt，免费）

公网部署**必须 HTTPS**（否则手机浏览器可能拦截、涉及安全）。用 Nginx 反代（`deploy/nginx.conf.example`）：
```bash
# 装 certbot 签证书
sudo apt install -y certbot
sudo certbot certonly --standalone -d 你的域名
# 用 deploy/nginx.conf.example 配置反代，指向证书路径
```
Nginx 同时处理：前端静态 + API + WebSocket（/api/ws）。详见 `nginx.conf.example`。

## 第 8 步：ICP 备案（国内必须）

- 阿里云控制台 → **ICP 备案** → 按引导提交（身份证/手机号/人脸）
- 审核期 1-3 周，期间域名不能对外
- 备案通过后，浏览器访问 `https://你的域名` 正常

## 常用运维命令

```bash
docker compose logs -f          # 看日志（确认 AI 引擎: 火山方舟）
docker compose restart          # 重启
docker compose down             # 停止（数据保留）
docker compose up -d --build    # 更新代码后重新构建
docker volume ls                # 看数据卷
```

## 常见问题

| 现象 | 解决 |
|---|---|
| 公网 IP:3000 打不开 | 安全组没放行 3000；或防火墙 |
| 部署后 AI 助手走规则引擎 | `.env` 没填 `ARK_API_KEY`；或模型名不对 |
| 手机访问提示不安全 | 还没配 HTTPS（必须配） |
| 备案中域名无法访问 | 备案是强制的，期间用 IP 测试 |
| node:sqlite 报错 | 用 node:24 镜像（Dockerfile 已改），`CMD` 已加 `--experimental-sqlite` |
