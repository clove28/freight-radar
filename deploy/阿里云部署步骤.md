## 第 1 步：放行 3000 端口（最容易忘，忘了就打不开）

控制台 → 服务器详情 → **防火墙 / 安全组** → 添加规则：

- 协议 **TCP**，端口 **3000**，来源 `0.0.0.0/0`

## 第 2 步：一条命令部署

控制台 → 服务器详情 → **远程连接**（网页版终端，不用装 SSH 工具），以 root 登录后粘贴：

```bash
curl -fsSL https://gitee.com/clove28/freight-radar/raw/main/deploy/bootstrap.sh -o /tmp/bootstrap.sh
bash /tmp/bootstrap.sh
```

脚本会自动完成：装 Docker → 从 Gitee 拉最新代码 → 生成 `.env` → 构建并启动 → 健康检查。
**中途会问你两个 key**（都可留空，留空也能跑）：

- `DeepSeek API key`：留空则 AI 助手走规则引擎（功能完整，文案是固定模板）
- `高德 AMAP_KEY`：留空则路线/天气走 Mock 估算

> 仓库是公开的，服务器直接 `git clone`，不需要给服务器配 Git 凭据。

## 第 3 步：验证

```bash
# 在服务器上
curl http://127.0.0.1:3000/api/health        # 应返回 {"ok":true,...}
```

然后手机/电脑浏览器打开 **`http://你的公网IP:3000`**，AI 助手试一句「帮我看看回临汾的黄豆粕单」，
有解释文案就说明整条链路通了。

## 第 4 步：日常运维（就这几条）

```bash
cd /opt/freight-radar

docker compose ps                # 看状态
docker compose logs -f           # 看日志（确认 AI 引擎是 DeepSeek 还是规则引擎）
docker compose restart           # 重启
docker compose up -d --build     # 更新代码后重建

# 更新到最新代码
git pull && docker compose up -d --build
```

改 key：`vim /opt/freight-radar/.env`，然后 `docker compose up -d`。

## 为什么可以不买域名

- 域名只是「好记的名字」，不是「能访问」的前提。公网 IP + 非 80/443 端口就能直接访问。
- **ICP 备案针对的是「域名解析到境内服务器」**，你根本没有域名，所以走不到备案流程。
- 代价是链接长得糙（`http://47.x.x.x:3000`）、且是 HTTP 明文：
  - 手机浏览器可能提示「不安全」，点「继续访问」即可；
  - **微信内置浏览器可能直接拦截**，发给别人时注明「请用手机浏览器打开」。

## 安全提醒（公网必看）

- 公开链接 = **公开的花钱入口**：别人能直接调你的 AI 助手消耗你的额度。
  - 上线后立刻去 DeepSeek 平台给这个 key 设**消费限额**（例如每天 ¥5）；
  - 脚本生成的 `.env` 里写的是 `AUTH_REQUIRED=0`（不登录也能看，适合面试演示）；
    想关掉这个口子就改成 `1` 再 `docker compose up -d`——代价是所有人都要先登录。
- `.env` 里是真实密钥：**不要提交到 git**（`.gitignore` 已排除），也不要贴到群里。
- 不做交易撮合、不代收运费，定位「决策工具」，合规风险最低。
